@plasma/chrome

Static reference

Every state of the shared chrome, rendered by ./chrome.css. Nothing here is styled by this page except the grey furniture around each frame — if a measurement is in question, read the class in the stylesheet rather than the markup.

Hover and focus states are live: mouse over a nav item, tab through a bar. The contrast correction is already applied — the active nav fill is #c2301a, never #ff5b3a.

05 · Item states

06 · Mobile

One treatment for both modes — the only difference is the chevron. Four destinations plus More, 48px minimum targets, and the tab bar is absolute inside the app frame, never fixed: iOS pans a fixed bar away from the screen edge when the keyboard opens.

Three destinations plus More is correct for Stock Control. Never pad the bar to five. The rule is "the fifth slot is always overflow", not "there are always five tabs".

App switching lives in the account sheet behind the avatar. Today's strip is overflow-x: auto with scrollbar-width: none, so on a narrow phone the fourth app can sit off-screen with nothing indicating it exists.
